# Orbitly Digital Marketing Agency

## Run locally
1. Install Node.js 20+
2. Open this folder
3. Run:
   npm install
   npm run dev

Open http://localhost:3000

## Deploy
Push the folder to GitHub and import the repository into Vercel.

## Notes
- Content is easy to edit directly in app/page.tsx.
- Replace placeholder case-study content with real client data.
- Connect the contact form to your preferred CRM/email service.
